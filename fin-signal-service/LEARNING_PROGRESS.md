## 第二課：課堂複習問答

記錄日期：2026-11-20。共 2 題，整理自實際課堂提問與回答。複習時先自己回答，再核對參考答案。

### 問題 1：部署時還需要開發工具嗎？

**課堂問題：** 如果把專案部署到伺服器，只提供 API，不在上面跑測試或檢查程式碼，pytest 和 Ruff 通常還需要安裝嗎？

**你的回答：**「不用吧」

**回饋：** 正確。只提供 API 時，通常不需要 pytest 和 Ruff；這些工具可放在開發環境或 CI 使用。

**參考答案：** 依目前專案，FastAPI、Uvicorn、Pydantic 屬於服務運作需要的依賴；pytest、pytest-asyncio、HTTPX、Ruff 則被放在額外的 dev 群組。正式環境通常只安裝所需的執行依賴。HTTPX 在其他專案也可能用於正式服務，應依實際用途分類。

**容易混淆：** dev 是專案自訂的額外依賴群組名稱，不是 Python 禁止在正式環境安裝的套件類型。不選 dev，也不會自動移除環境裡既有的開發工具。

### 問題 2：這行安裝指令做了什麼？

```bash
python3 -m pip install -e ".[dev]"
```

**課堂問題：** 請用自己的話說明這行指令：安裝哪個專案、dev 是什麼、-e 有什麼用途？

**你的回答：**「主要是使用 pip 的工具去安裝 [dev] 裡面的依賴」

**回饋：** 正確說出 dev 的用途，再補上「目前專案」與「可編輯模式」就完整了。補充說明後，你表示已了解。

| 部分 | 意思 |
| --- | --- |
| `python3 -m pip` | 使用這個 Python 環境裡的 pip |
| `install` | 執行安裝 |
| `.` | 安裝目前資料夾的專案，以及基本 dependencies |
| `[dev]` | 額外安裝專案定義的 dev 群組依賴 |
| `-e` | 使用可編輯模式，修改一般 Python 原始碼後通常不必重新安裝 |

**完整參考答案：** 使用這個 Python 的 pip，以可編輯模式安裝目前專案，並一起安裝基本依賴和 dev 群組的開發工具。

**容易混淆：** 這行不只是安裝 dev。若修改依賴或部分套件設定，仍可能需要重新執行安裝。引號可避免 shell 將方括號當成檔名比對符號。
